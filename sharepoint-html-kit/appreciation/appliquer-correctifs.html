Correctifs v3.1 – Appréciation de la contribution

Rend l'application compatible avec les « pages HTML » SharePoint, sans toucher à vos images ni à vos données.

1. Choisir votre fichier

Glissez ici votre fichier appreciation.html (version 3.0), ou cliquez pour le choisir.

    Ce que font les correctifs

    CorrectifPourquoi
    Message « Cette page ne peut pas s'exécuter ici »Si SharePoint bloque le JavaScript (page wiki classique), l'utilisateur voit une explication au lieu d'un écran de mot de passe qui ne répond pas.
    Écran de mot de passe sauté si le stockage est bloquéDans une page HTML SharePoint, localStorage est interdit : l'écran restait figé.
    « 💾 Copie locale » fonctionne toujoursSans stockage, le bouton télécharge quand même le fichier .json (avant, le téléchargement était sauté si l'enregistrement dans le navigateur échouait).
    Bandeau « Ouvrir l'application » non bloquantIl s'affichait dès que la page était dans un cadre, donc toujours dans une page HTML SharePoint.
    Bandeau d'information adaptéExplique quoi faire quand la sauvegarde dans le navigateur est impossible.
    Dépôt possible même si les fenêtres de confirmation sont bloquéesDans le bac à sable, confirm() peut répondre « Non » sans s'afficher : le bouton « Déposer » ne faisait alors plus rien. Les messages d'erreur s'affichent aussi dans la page.
    Numéro de version 3.1Pour savoir quelle version est en ligne.
