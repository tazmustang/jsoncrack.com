# À faire, dans l'ordre

1. **Remplacer le fichier.** Déposez `appreciation-cadres-v3.4.html` dans la bibliothèque. Supprimez ensuite l'ancien `appreciation-cadres-v3.3.html` : le nom a changé, il n'y a donc rien à remplacer.
2. **Créer la bibliothèque Dossiers_Appreciations**, si ce n'est pas déjà fait (guide ETAPE-1, partie B). La liste Depot_Appreciations est faite ✅.
3. **Tester sur le poste** (pas dans l'aperçu) :
   - ⤓ Télécharger le fichier depuis la bibliothèque, puis l'ouvrir ;
   - créer le mot de passe ;
   - 💾 Copie locale : un fichier `.json` arrive dans Téléchargements ;
   - ☁️ Déposer sur SharePoint : un fichier `depot-….json` arrive ; ensuite « Ouvrir le formulaire de dépôt », joindre ce fichier et enregistrer ;
   - 📂 Ouvrir « Mes dossiers » ;
   - 🖨️ Aperçu PDF.
4. **M'envoyer les résultats** (✅ ou ❌, avec des captures). Ensuite, on construit le flux Power Automate « AC - Traiter un dépôt ».
5. **Répondre aux 3 questions :**
   - l'ordre des postures (Innovant avant Responsable, comme dans le Word ?) ;
   - la question de la section C du cadre sans équipe ;
   - la virgule dans « suivantes, donnez ».
