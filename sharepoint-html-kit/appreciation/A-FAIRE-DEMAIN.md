# À faire, dans l'ordre

## 1. Déposer la dernière version de l'application (5 min)
- Téléchargez le fichier `appreciation-cadres-v3.3.html` reçu en dernier (celui avec le lien stable).
- Déposez-le dans votre bibliothèque « Appréciation de la contribution des cadres ».
- Si un fichier du même nom existe : choisissez **Remplacer**. Ne supprimez pas l'ancien.
- Ne modifiez pas le fichier dans le Bloc-notes : les adresses sont déjà inscrites.

## 2. Créer la liste de dépôt et la bibliothèque des dossiers (30 min)
Suivez **ETAPE-1-LISTE-ET-BIBLIOTHEQUE.docx**, clic par clic :
- liste **Depot_Appreciations**, avec les pièces jointes activées ;
- bibliothèque **Dossiers_Appreciations**, avec ses 6 colonnes et ses versions.

Les noms doivent être écrits **à la lettre**, avec les majuscules et le trait de soulignement.

## 3. Tester dans SharePoint (10 min)
Ouvrez le fichier depuis la bibliothèque et notez ✅ ou ❌ pour chaque point :
- l'application s'ouvre **sans** écran de mot de passe, avec le bandeau jaune ;
- vous choisissez un type de poste et remplissez un champ ;
- **💾 Copie locale** : un fichier `.json` arrive dans vos Téléchargements ;
- vous actualisez la page (F5), puis **📁 Charger un dossier** avec ce fichier : les données reviennent ;
- **☁️ Déposer sur SharePoint**, puis **Ouvrir le formulaire de dépôt** : le formulaire de la liste s'ouvre, avec « Ajouter des pièces jointes » ;
- **📂 Ouvrir « Mes dossiers »** : la bibliothèque Dossiers_Appreciations s'ouvre ;
- **🖨️ Aperçu PDF** : la fenêtre d'impression s'affiche ;
- Aide-mémoire › **✉️ Envoyer** : Outlook s'ouvre.

## 4. M'envoyer les résultats
- Envoyez la liste des ✅ et des ❌, avec une capture d'écran de ce qui ne fonctionne pas.
- Je corrige ce qui bloque, puis on construit ensemble le **flux Power Automate « AC - Traiter un dépôt »**, une étape à la fois. Sans ce flux, un dépôt reste dans la liste sans courriel ni dossier officiel.

## 5. Questions à me répondre quand vous aurez un moment
1. **Ordre des postures** : faut-il suivre le Word (Innovant avant Responsable) ? Aujourd'hui, l'application affiche Responsable avant Innovant.
2. **Cadre sans équipe, section C** : faut-il garder la question du Word du 15 octobre (« …ayant fait l'objet d'actions ou d'efforts particuliers… ») ? C'est celle que j'ai mise.
3. **Virgule** : faut-il garder la virgule dans « Pour chacune des compétences suivantes, donnez… » ?

## Ne pas faire
- Ne pas mettre le fichier dans **Pages du site** : l'option « Page HTML » n'y est pas encore activée.
- Ne pas supprimer l'ancienne liste **AppreciationsCadres_Suivi** pour l'instant.
- Ne pas retirer le mot de passe de l'application, même si Copilot le suggère : il est déjà sauté automatiquement dans SharePoint.
