Règles de construction

  • Les noms en gras sont les noms exacts à donner aux actions (menu … › Renommer) : les expressions en dépendent.
  • Les expressions complètes sont dans 5-GUIDE-FLUX-DEPOT (numéros de section indiqués sur les cartes). Collez-les dans l'onglet Expression (fx).
  • Mode test : variable modeTest = true → tous les participants ont votre adresse et le rôle est celui choisi dans l'application. Pour le pilote réel : false.
  • Phase 1 : construisez avec votre compte, dans le site de test, avec des données fictives. Phase 2 : compte de service et site dédié (TI).
  • Ancien schéma → nouveau : la variable fusion s'appelle maintenant dossier, messageSucces devient message, et role / clesPermises / nomFichierDossier / idElementDossier sont remplacés par les actions Composer Role, ClesPermises, etc.
