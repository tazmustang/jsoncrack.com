# 1. En bref

| | |
|---|---|
| **Public** | Supérieur(e)s immédiat(e)s et hiérarchiques, directeurs et directrices |
| **Durée** | Environ **5 minutes** (4 chapitres) |
| **Outils** | **Gratuits**, déjà sur votre poste : Outil Capture d'écran de Windows (enregistrement) et **Clipchamp** (montage, inclus dans Microsoft 365) |
| **Diffusion** | **Microsoft Stream** (SharePoint ou OneDrive), avec un lien dans l'annonce et dans le guide d'utilisation |
| **Temps de préparation** | Environ 1 h pour l'enregistrement et 1 h pour le montage |

**Fichiers fournis :**
- les cartes de titre (01), de chapitres (02 à 05) et de fin (99), en 1920 × 1080 ;
- les sous-titres prêts à importer (`Sous-titres-video-gestionnaires.srt`) ;
- ce scénario.

# 2. Préparer (la veille)

1. **Faites l'enregistrement en PréProd**, jamais en Prod, avec des **données fictives**. Aucun vrai nom ni vraie évaluation ne doit apparaître.
2. **Créez un dossier de démonstration** avec une collègue de l'équipe, qui joue la personne en appréciation. Par exemple « Tremblay, Julie (démo) » :
   - elle remplit les sections A, B (ses cotes), C, D et F avec du texte fictif ;
   - elle clique sur **Aviser**, puis sur **Certifier**.
3. **Vous**, vous jouez le **supérieur immédiat** : le dossier doit être « À approuver par moi ».
4. **Préparez l'écran :**
   - fermez Teams et Outlook (ou coupez les notifications : **Paramètres Windows › Système › Notifications › Ne pas déranger**) ;
   - fermez les onglets inutiles ;
   - zoom du navigateur à **100 %** ;
   - mettez l'application en **plein écran** (**F11**).
5. **Imprimez** le texte de narration (partie 3) pour le lire pendant l'enregistrement.
6. **Micro :** utilisez un casque avec micro. Le son est plus clair qu'avec le micro de l'ordinateur.

# 4. Enregistrer (Outil Capture d'écran de Windows)

1. Ouvrez l'**Outil Capture d'écran** (menu Démarrer › tapez « Capture »), ou appuyez sur **Windows + Maj + R**.
2. Cliquez sur l'icône **caméra** (Enregistrer), puis sur **+ Nouveau**.
3. Sélectionnez **tout l'écran**.
4. Vérifiez que le **micro** est activé (icône micro).
5. Cliquez sur **Démarrer**. Un compte à rebours de 3 secondes s'affiche.
6. Faites un chapitre à la fois. **Arrêtez** l'enregistrement entre les chapitres : il est plus facile de refaire un petit morceau.
7. **Enregistrez** chaque fichier : Chapitre1.mp4, Chapitre2.mp4, etc.

*Solution de rechange :* PowerPoint › onglet **Enregistrer** › **Enregistrement d'écran**, ou une réunion Teams seule avec vous-même, en partage d'écran et enregistrement.

# 5. Monter (Clipchamp, gratuit)

1. Ouvrez **Clipchamp** (menu Démarrer, ou depuis Office.com › Applications). Connectez-vous avec votre compte de la Ville.
2. **Créer une vidéo**, format **16:9**.
3. **Importer un média** : les vidéos des chapitres et les cartes .png fournies.
4. Glissez-les dans la **chronologie**, dans l'ordre : 01-Carte-titre (5 s), Chapitre-1 (3 s), vidéo 1, Chapitre-2, vidéo 2, Chapitre-3, vidéo 3, Chapitre-4, vidéo 4, 99-Carte-fin (5 s).
5. **Coupez** les silences et les erreurs : placez le curseur, puis **ciseaux** (S).
6. **Sous-titres :**
   - **option 1 :** **Sous-titres › Activer les sous-titres automatiques**, langue **Français (Canada)**, puis corrigez les mots mal compris ;
   - **option 2 :** importez le fichier **Sous-titres-video-gestionnaires.srt**, si les minutages correspondent.
7. *(Facultatif)* Mettez en évidence les clics importants : **Éléments graphiques › Formes**, avec une flèche ou un cercle or #857650.
8. **Exporter** › **1080p**.

# 6. Diffuser

1. Déposez la vidéo (.mp4) dans une bibliothèque SharePoint RH, ou dans OneDrive. Elle s'ouvre automatiquement dans **Stream**.
2. **Partager** › « Personnes de la Ville de Québec disposant du lien », ou le groupe des gestionnaires.
3. Dans Stream, vérifiez que les **sous-titres** sont activés (Paramètres de la vidéo › Transcription et sous-titres).
4. Ajoutez le lien :
   - dans le **message d'annonce** ;
   - dans le **guide d'utilisation** ;
   - et, si possible, dans l'écran **Aide** de l'application.
5. Faites valider la vidéo par le **Service des communications** avec la charte graphique, s'il y a lieu.

# 7. Vérification avant la diffusion

| ✔ | Point |
|---|---|
| ☐ | Aucun vrai nom, aucune vraie évaluation, aucun courriel personnel visible |
| ☐ | Bandeau « PRÉ-PROD » ou environnement de test : acceptable, ou masqué au montage |
| ☐ | Son clair, sans bruit de fond |
| ☐ | Sous-titres en français, corrigés |
| ☐ | Durée de 6 minutes au plus |
| ☐ | Les noms des boutons correspondent à la version en production |
